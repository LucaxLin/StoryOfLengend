# 一、游戏核心设定

## 1.1 世界观背景

旧时代，人类凭顶尖科技君临星球，肆意改造环境，构筑起辉煌的文明壁垒。
直到那一天，一颗血色流星划破天幕。无人察觉的无形电磁波，如病毒般席卷全球 —— 电子设备从杂音频发走向彻底瘫痪，热武器尽数哑火，人类引以为傲的科技霸权轰然崩塌。
更恐怖的是，无数形态诡谲、结构悖逆常理的异界生物破土而出，它们的铁蹄踏碎城市，将人类文明推向毁灭的深渊。
绝境之中，部分人类觉醒了超凡异能；与此同时，科学家们发现，这些诡异生物的尸骸中，藏着末世里唯一的能源核心 ——**能量晶石**，其躯体更是能锻造成具备特殊效果的道具。
人类的反抗自此打响，高层将这一天定为**新元历元年**。
时光流转，新元历 730 年。
一处资源濒临枯竭的废弃营地内，最后的火种在寒风中摇摇欲坠。
而属于他们的故事，正要拉开序幕。

## 1.2 核心玩法

- **肉鸽核心**：每局游戏为随机生成的关卡（房间），包含战斗房、商店房、遗物房、休息房、精英房、BOSS 房，关卡路径随机，死亡后除“能量晶石”外所有进度重置。

- **角色养成**：开局选择基础角色，局内通过技能替换、遗物收集、药水强化构建 Build，局外通过**能量晶石**解锁新角色/初始技能。

- **回合制战斗核心**：
  单场战斗为回合制，以“行动点（AP）”为核心资源，玩家每回合固定获得 2 点行动点（可通过遗物/药水提升）。

- 玩家阶段：消耗行动点释放技能（不同技能消耗 1-2 点 AP）、使用药水，行动点耗尽或主动结束回合后进入敌人阶段。

- 敌人阶段：战斗开始前显示本回合敌人行动预览（技能名称、伤害值、特殊效果），敌人行动固定（无 AP 消耗），多敌人场景按优先级依次行动。

- 胜利条件：击败所有敌人；失败条件：玩家生命值归 0。

## 1.4 技能系统

### 1.4.1 技能分类

| 分类     | 说明                                                                 | AP 消耗 |
| -------- | -------------------------------------------------------------------- | ------- |
| 攻击技能 | 核心输出手段，分单体/群体/持续伤害型，对应角色特性                   | 1-2     |
| 防御技能 | 生存手段，分减伤/护盾/闪避/回血型，部分附带增益                      | 1       |
| 辅助技能 | 功能性技能，分控场（眩晕/减速）/增益（攻速/攻击力）/Debuff（易伤）型 | 1-2     |

### 1.4.2 技能规则

- 初始：每个角色默认携带 1 个攻击技能+1 个防御技能，可直接使用。

- 上限：局内最多解锁 4 个技能槽（初始 2 个，通过关卡/遗物解锁 2 个），可自由替换已获得技能。

- 获取：战斗房胜利后概率掉落技能卷轴、商店房购买、精英房/BOSS 房必掉稀有技能卷轴。

- 技能品质：普通 → 稀有 → 史诗 → 传说，品质越高效果越强+AP 消耗可能降低（如传说破甲斩 AP 消耗从 2→1）。

## 1.5 遗物系统

### 1.5.1 遗物分类

| 分类     | 说明             | 示例                                                                                    |
| -------- | ---------------- | --------------------------------------------------------------------------------------- |
| 角色专属 | 仅对应角色可生效 | 战士：每击杀 1 个敌人，下回合 AP+1；刺客：暴击后恢复 1 点 AP；法师：持续伤害时长+1 回合 |
| 通用型   | 所有角色生效     | 每回合初始 AP+1（上限 3）；受到攻击后有 10%概率获得 1 点 AP                             |
| 负面遗物 | 高收益+负面效果  | AP 上限+1，但每回合结束损失 5 点生命值；技能 AP 消耗-1，但防御降低 50%                  |

### 1.5.2 遗物规则

- 获取：遗物房随机刷新 1-3 个遗物（选 1）、精英房/BOSS 房必掉稀有遗物、商店房购买。

- 数量上限：单局携带遗物数量无限制，支持携带各类负面遗物，满足不同玩法策略需求。

- 叠加与获取规则：单局内相同遗物不会重复出现；同类通用遗物效果不可叠加（仅生效单个效果），角色专属遗物仅生效 1 个最高品质。

## 1.6 药水系统

### 1.6.1 药水分类

| 分类     | 效果                                                                    | AP 消耗 |
| -------- | ----------------------------------------------------------------------- | ------- |
| 即时恢复 | 立即恢复生命值（如：恢复 30 点生命、恢复 50%最大生命）                  | 1       |
| 临时增益 | 持续 1-3 回合（如：本回合 AP+2、暴击率+30%、免伤 50%）                  | 1       |
| 功能型   | 一次性效果（如：清除所有技能冷却、本回合敌人无法行动、刷新当前可用 AP） | 1-2     |

### 1.6.2 药水规则

- 获取：战斗房概率掉落、商店房购买、休息房随机刷新（可免费领取 1 瓶）。

- 携带上限：单局最多携带 5 瓶药水，使用后消失。

- 使用时机：仅在玩家回合使用，消耗对应 AP，临时增益药水效果仅在当前/后续回合生效。

## 1.7 能量晶石系统

- 每日任务：完成每日任务（如“进行 3 局游戏”“获得 1 个传说技能”）奖励能量晶石。

# 二、开发环境与技术栈

## 2.1 基础环境

- 引擎：Cocos Creator 3.8+（支持 3D/2D，采用 2D 像素风，通过像素着色器强化复古颗粒感，角色与场景以 8-bit/16-bit 像素精度绘制）。

- 编程语言：TypeScript（主逻辑）+ JavaScript（辅助）。

- 资源管理：Cocos Asset Manager（资源加载/缓存）。

- 数据存储：LocalStorage（单机数据，能量晶石/解锁内容/成就）+ Json（配置表）。

## 2.2 核心技术模块

| 模块           | 技术实现要点                                                                                                                                        |
| -------------- | --------------------------------------------------------------------------------------------------------------------------------------------------- |
| 随机关卡生成   | 采用“房间节点+路径算法”，预设房间模板（战斗/商店/遗物等），随机生成关卡路径和房间内容                                                               |
| 回合制战斗系统 | 基于“回合管理器”单例，区分玩家回合/敌人回合，实现 AP 计算、技能冷却、行动预览、伤害结算；状态机管理角色/敌人行动（攻击/防御/使用道具）              |
| 技能系统       | 技能抽象为基类（SkillBase），派生攻击/防御/辅助技能子类，增加 AP 消耗配置，通过事件驱动技能释放                                                     |
| 数据管理       | 单例模式（DataManager）管理局内数据（角色属性/技能/遗物/药水/当前 AP/回合数），局外数据持久化存储到 LocalStorage                                    |
| 界面系统       | 基于 Cocos UI 组件，采用像素风 UI 元素，新增 AP 显示（像素数字动态跳动）、敌人行动预览面板（像素图标+文字组合）、回合切换动画（像素化闪烁过渡效果） |

# 三、开发计划与优先级

## 3.1 第一阶段（核心功能-回合制基础）

1. 完成数据配置层（补充回合制字段：AP、冷却回合、持续回合）。

2. 实现回合管理器核心逻辑（回合切换、AP 管理、敌人行动预览）。

3. 实现角色/敌人基础逻辑（回合制攻击、技能释放、AP 消耗）。

4. 完成角色选择界面和战斗 UI（新增 AP 显示、敌人行动预览）。

## 3.2 第二阶段（肉鸽核心+回合制完善）

1. 实现随机关卡生成系统（房间类型、路径）。

2. 完成技能替换、遗物收集、药水使用的回合制逻辑。

3. 实现精英房/BOSS 房的高难度回合制战斗（多敌人、复杂技能）。

4. 完成 buff/debuff 系统（持续效果、回合刷新）。

## 3.3 第三阶段（局外养成+优化）

1. 实现能量晶石解锁角色/初始技能逻辑。

2. 完成成就系统与每日任务模块，完善能量晶石获取途径。

3. 优化战斗体验，调整技能平衡与敌人 AI 行动逻辑。

4. 添加像素风音效（8-bit 电子音效）、帧动画（角色技能像素帧动画）等资源，强化复古沉浸感。

5. 进行兼容性测试与 BUG 修复，确保核心功能稳定运行。
